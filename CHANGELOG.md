# Changelog

All notable changes to TerminalAt should be recorded here.

The project uses semantic-style version numbers in the `VERSION` file.

## 1.0.0 — 2026-08-24

- Initial GitHub-ready release.
- Spotlight-backed folder search within the user's home directory.
- Recent-folder history and pinned favorites.
- Direct path entry and standard macOS folder chooser.
- Drag-and-drop folder opening.
- Keyboard navigation and global `⌥⌘T` shortcut.
- Native opening of Apple Terminal at the selected directory.
- Separate build and install scripts.
- macOS GitHub Actions build verification.
